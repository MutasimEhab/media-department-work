صور واجهات نظام أعمال قسم الإعلامية - النسخة الحالية

هذه الصور ملتقطة من كود النسخة الحالية نفسها وليست صورًا مولدة بالذكاء الاصطناعي.
تم تشغيل النسخة محليًا ببيانات تجريبية فقط لفتح جميع الواجهات بدون استخدام أو تعديل بيانات الموقع الحقيقية.

عدد الصور: 31
تشمل: تسجيل الدخول، الرئيسية، إضافة عمل، الكشف، المشاريع، تفاصيل المشروع، التكليفات، المواد الإعلامية، الأعمال غير المتزامنة، التعميمات، مركز الإشعارات، الملف الشخصي، جميع تبويبات لوحة الأدمن، النسخ الاحتياطي، البحث الشامل، الجرس، قائمة المستخدم، وواجهات الجوال.
